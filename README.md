# Запуститить демо контейнер

> Сначала необходимо создать файл .env в корне репозитория. Файл example.env предоставляет пример такого файла.

Затем выполнить команду

```bash
docker compose up
```

Взаимодействовать с сервисом можно через [интерактивную документацию API](http://localhost:11118/docs)

# Описание

Сервис предоставляет API для получения информации об организациях и зданиях, связанных с географическими координатами.
Он поддерживает поиск организаций по категориям и подкатегориям (до трёх уровней вложенности), а также поиск зданий и организаций по заданным координатам.

Основные возможности:

- Получение информации об организациях, зданиях и категориях.

- Поиск организаций по геолокации и категориям.

- Работа с географическими данными через тип Geography (POINT) и расширение PostGIS.

- Автоматическая генерация интерактивной документации OpenAPI.

Технологический стек:

- FastAPI — фреймворк для построения REST API.

- SQLAlchemy + GeoAlchemy2 — ORM и поддержка пространственных данных.

- PostgreSQL + PostGIS — база данных с геопространственными возможностями.

# Что происходит во время запуска демо контейнера

> Перед запуском контейнеров необходимо создать файл .env в корне репозитория. Примеры значений находятся в файле example.env

1. Билд образа приложения из uv образа (ghcr.io/astral-sh/uv:python3.13-alpine)
2. Скачивается postgis/postgis
3. Контейнер приложения ждет запуска базы данных
4. Применяются миграции
5. Выполняются тесты
6. Создаются тестовые данные
7. Запускается сервис REST API

## Полезные команды

### run migrations

```bash
alembic upgrade head
```

### create migration file

```bash
alembic revision --autogenerate -m "init"
```

### run tests

```bash
pytest -vv tests
```
